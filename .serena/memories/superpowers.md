# Memory: superpowers

Skills for agentic development workflows.

## Available Skills
- `superpowers:using-superpowers` - intro to skills (always invoke first)
- `superpowers:subagent-driven-development` - run plan tasks in parallel with subagents
- `superpowers:executing-plans` - execute a multi-step implementation plan
- `superpowers:brainstorming` - explore requirements before creative work
- `superpowers:systematic-debugging` - debug bug/test failures systematically
- `superpowers:verification-before-completion` - verify changes end-to-end
- `superpowers:finishing-a-development-branch` - merge/PR/cleanup options

## When to Invoke
Per the using-superpowers skill: if there's even a 1% chance a skill applies, invoke it. Process skills (brainstorming, debugging) before implementation skills.
