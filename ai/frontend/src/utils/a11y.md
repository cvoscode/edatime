# ai/frontend/src/utils/a11y.md

> Accessibility utilities: ARIA live region announcements and a global loading indicator.

## Functions
- `announce(message: string, priority?: 'polite' | 'assertive'): void`
  - Announces a message to screen readers via an ARIA live region.
- `announceChartLoading(columns: string[]): void`
  - Announces chart loading state for one or more columns.
- `announceFilterChange(filterName: string, value: string): void`
  - Announces a filter change event.
- `announceDataUpdate(pageName: string): void`
  - Announces a data update on a given page.
- `showGlobalLoading(message?: string): void`
  - Shows the global loading indicator in the header.
- `hideGlobalLoading(delay?: number): void`
  - Hides the global loading indicator after an optional delay.
