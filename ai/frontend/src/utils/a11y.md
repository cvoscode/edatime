# a11y.ts

Accessibility utilities for EdaTime, providing ARIA live region announcements and global loading indicator management.

## Functions

```typescript
function announce(message: string, priority?: 'polite' | 'assertive'): void
```

Announce a message to screen readers via ARIA live region.

```typescript
function announceChartLoading(columns: string[]): void
```

Announce chart loading state.

```typescript
function announceFilterChange(filterName: string, value: string): void
```

Announce filter changes.

```typescript
function announceDataUpdate(pageName: string): void
```

Announce data updates.

```typescript
function showGlobalLoading(message?: string): void
```

Show global loading indicator.

```typescript
function hideGlobalLoading(delay?: number): void
```

Hide global loading indicator.

```typescript
function updateDataFreshness(source: string): void
```

Update data freshness indicator.

```typescript
function setDataFreshnessStale(): void
```

Set data freshness to stale.

```typescript
function getDataFreshnessAge(): number | null
```

Get age of data freshness in ms.

```typescript
function isDataStale(thresholdMs?: number): boolean
```

Check if data is stale.

```typescript
function showKeyboardShortcutsHelp(): void
```

Show keyboard shortcuts help modal.

```typescript
function hideKeyboardShortcutsHelp(): void
```

Hide keyboard shortcuts help modal.

```typescript
function showWhatsNewModal(): void
```

Show what's new modal.

```typescript
function hideWhatsNewModal(): void
```

Hide what's new modal.

```typescript
function initAccessibilityShortcuts(): void
```

Initialize keyboard shortcut toggle.
