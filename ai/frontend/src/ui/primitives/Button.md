> Action button component.

## Function: Button
- `Button(props: ButtonProps): HTMLButtonElement`
  - Creates a styled button element.

## ButtonProps
- `label: string`
- `className?: string`
- `onClick?: () => void`
- `disabled?: boolean`
- `type?: 'button' | 'submit' | 'reset'`
