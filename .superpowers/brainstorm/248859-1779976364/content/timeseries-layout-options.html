Two-band workspace

Keeps the current mental model, but makes the top area cleaner, denser, and stable. Best if you want familiar behavior with fewer overlaps.

Command bar + utility shelf

More product-like and modern. Primary actions stay in one command row, secondary tools drop into a shorter utility shelf below.

C · Compact analyst console
Search + collapse
Multi-line chips
Export
Analytics + zoom
Draw / labels / notes inline
View state
Chart

Compact analyst console

Most aggressive density reduction. Better for expert workflows, but it pushes the page toward a control console instead of a visibly grouped toolbar layout.

My recommendation

  • B gives the cleanest modern hierarchy.
  • It solves the overlap problem without hiding tools.
  • It gives us a better place to introduce a designed, app-wide toast system.

Tradeoff

  • A is the safest and lowest-risk.
  • C is the densest, but easier to over-compress.
